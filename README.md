# JSON DSL Rule Engine Example

This example demonstrates how a JSON Domain-Specific Language (DSL) can define business rules. It includes a Python rule engine that interprets and executes these JSON-defined rules against input data. The example highlights that while rules are expressed in a 'no-code' JSON format, underlying 'code' is still required to process and apply them, illustrating the article's core concept.

## Language

`python`

## How to Run

Save the code as `main.py`. Run from your terminal: `python main.py`
